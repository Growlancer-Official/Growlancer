# 🌟 About Growlancer

Growlancer is an AI-powered freelancing marketplace built to simplify hiring and freelancing with intelligent matching, secure escrow payments, transparent collaboration, and modern project management.

Our mission is to make freelancing faster, safer, and smarter for both businesses and professionals.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Growlancer-Official/Growlancer.git
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

---

# 🔐 Environment Variables

Create a `.env` file:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
VITE_RAZORPAY_KEY=
VITE_PAYPAL_CLIENT_ID=
VITE_SENTRY_DSN=
```

> Never commit secrets or API keys to the repository.
